# 

If you want to contribute to the collection you can either donate old/unused pipes (reach out to me directly) or [open an issue/pull request](https://github.com/pax-global/pax.global/issues/new) and update missing or inaccurate information.

1. Please use the this title convention [pipe_info] and add a link to the pipe you are referencing when requesting a change.
2. Make sure to include reasonable proof (e.g. link to the source of the info). Word of mouth / recollection can also act as proof, given `bona fide`.
3. Clearly specify which fields are to be updated.
